HERO MODEL (optional - a built-in hero is used if missing)
  hero.glb   or   hero.fbx      in this folder

Get one: mixamo.com (free Adobe login) -> Characters -> pick e.g. Swat / Vanguard
-> Download, Format "FBX Binary (.fbx)", Pose "T-pose". Save as hero.fbx.
(The loader scales it to 1.8 m and puts its feet on the ground automatically.)

ANIMATIONS: put the 10 files in the "animations" folder (see its README.txt).
If you add a real hero, add ALL 10 animations, otherwise missing ones use
built-in motion that only fits the built-in hero.
