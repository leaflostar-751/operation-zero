Mixamo -> pick the SAME character -> search each animation -> Download:
  Format: FBX Binary (.fbx)   Skin: Without Skin   FPS: 30   "In Place": see table

 file name         Mixamo search name                         In Place?
 idle.fbx          Breathing Idle                             no
 walk.fbx          Walking                                    YES
 run.fbx           Standard Run (or Running)                  YES
 sprint.fbx        Fast Run (or Sprint)                       YES
 jump.fbx          Jump Up / Jumping Up                       YES
 fall.fbx          Falling Idle                               no
 land.fbx          Falling To Landing / Hard Landing          YES
 crouch.fbx        Crouching Idle                             no
 crouch-walk.fbx   Crouched Walking  (crouch_walk.fbx also ok) YES
 turn.fbx          Left Turn                                  YES

.glb versions with the same names also work.
